Teacher Guide & How to Explore

Pedagogical Model: OBSERVE → THINK → ANSWER → CHECK → DISCOVER


This explorer avoids giving property facts immediately. Students rotate solids, colour faces, count faces/edges/vertices, solve mysteries, compare solids and connect shapes to real life.


Classroom Usage Tips:

  • Use on interactive whiteboards for whole-class discovery.
  • Encourage pairs to discuss before clicking “CHECK ANSWER”.
  • Use the Mystery Shape, Comparison Lab and Sorting Game to build mathematical reasoning.
