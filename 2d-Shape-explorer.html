      Teacher Guide & How to Explore

      Pedagogical Model: SEE → EXPLORE → OBSERVE → THINK → WRITE → CHECK → REFLECT


      This TLM avoids giving learners pre-written shape facts. Instead, students are prompted to count sides and vertices, test angle guides, and rotate shapes to construct spatial knowledge actively.


      Classroom Usage Tips:

      • Use on smart interactive whiteboards for whole-class discovery.
      • Encourage pairs to discuss before clicking "CHECK ANSWER".
      • Use the "Compare Shapes" tab when teaching similarities between geometric figures.
